01Manifesto

Your machine should answer to you — not to a quarterly earnings call.

Modern Windows ships with a parade of background services that phone home, harvest behavior, and starve your hardware of the cycles you paid for. VOIDTUNE is a quiet rebellion — a curated set of registry, service, and policy edits that restore the operating system to something closer to a tool.

Every change is documented, every change is reversible, and every line of source is on GitHub. There is no premium tier, no telemetry, no dark pattern. This is what software used to feel like.

Is it safe? Can I undo the changes?+
Yes. Every tweak is fully reversible, and VOIDTUNE writes a registry backup before each apply. The Restore tab rolls anything back to Windows defaults in one click.
Do I need to run it as administrator?+
No manual step — VOIDTUNE requests admin in its manifest, so Windows shows the UAC prompt automatically on launch and it runs elevated. Tuning services, the registry and the firewall requires elevation.
Will it disable Windows Update or my antivirus?+
The SAFE and EXTREME tiers leave Windows Security fully on. Only the opt-in NUCLEAR tier — hidden behind an explicit confirmation — touches Defender, SmartScreen, UAC or the Firewall, and every one of those is reversible.
Installer or portable — which do I pick?+
Both are self-contained (no .NET to install). The MSI gives you Start Menu + Desktop shortcuts, a clean uninstall and built-in auto-update. The portable zip just extracts and runs — nothing written outside the folder.
Does it phone home or collect data?+
Zero telemetry. The only network request is an optional check against GitHub for a newer release on launch, which you can turn off in Settings.
Which Windows versions are supported?+
Windows 10 (build 19041 / 20H1 and newer) and Windows 11, 64-bit. Intel, AMD and NVIDIA hardware are auto-detected for architecture-specific tweaks.
How do I report a bug or ask for help?+
Open an issue on GitHub or drop into the Discord server. Both are watched — bug reports are welcome on either.
